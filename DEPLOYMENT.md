# Publishing the portfolio

1. Open the repository settings: https://github.com/shubhamnov/shubham-portfolio/settings/pages
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for the Pages deployment to complete. The expected site URL is https://shubhamnov.github.io/shubham-portfolio/.

The main portfolio is in `index.html`. The site is static and does not require a build step.
